# 麻雀 点数ドリル

スマホで暇な時間に麻雀の点数計算を練習できるWebアプリ。`index.html` をブラウザで開くだけで動きます。

## モード
- **翻符→点**：翻・符・親子・ツモロンから点数を4択で答える
- **符計算**：手牌と条件から符を答える（内訳つき解説）
- **手牌→点**：手牌から点数を答える（役・符・点数の解説）
- **早見表**：子／親の点数表

## ルール
- 出題は50符以下のよく出る形
- 赤ドラ・本場・切り上げ満貫なし、連風牌の雀頭は4符
- 役満になる手は出題しない
- 成績はブラウザの localStorage に保存
